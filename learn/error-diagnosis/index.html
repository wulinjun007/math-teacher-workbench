错误诊断：从"打叉"到"追问"

v0.1.0 草稿 · 未复核 教材未映射 先修 U2 更新 2026-10-02

1教学困难与先备条件

教学困难：学生作业中的单调性错误反复出现——漏写区间、量词不完整、拿特例当证明；教师批改时只打叉或写"错"，学生改了答案却没改理解。

先备条件：完成 U2（或你已能独立完成"任取两点"的符号论证）——诊断卡里的追问全部指向定义要素，自己不熟定义就写不出追问。

材料边界：练习中不需要、也不应该录入学生姓名或成绩；诊断对象是"错误类型"，不是"某个学生"。

本单元的可观察目标：对三类典型错误中的每一类，教师能写出一条指向定义要素的追问，和一句学生可以自己执行的修正动作。

2示范：错误—追问—修正卡

三类错误分别对应定义的三个要素：区间（在哪里比）、量词（怎么取点）、论证（为什么成立）。诊断的第一步永远是定位类型，而不是判断对错。

错误类型典型原话教师追问修正动作（学生可执行）
遗漏区间
在哪里比		 "f(x)=1/x 是减函数。" "你是在哪个范围上比较的？取 x1=−1、x2=1，比较一下 f(x1) 和 f(x2)。" 先写出区间，再说升降：f(x) 在 (−∞,0) 和 (0,+∞) 上分别递减（并集上不成立）。
量词不完整
怎么取点		 "x 越大 y 越大。" "'越大'是指哪两个 x？任取两点、在同一个区间里，你怎么比较？" 改说完整：在区间内任取 x1<x2，都有 f(x1)<f(x2)。
特例代证明
为什么成立		 "f(1)<f(3)，所以在 [0,3] 上递增。" "1 和 3 能代表 [0,3] 里的所有点吗？再取 x=2 试试；那剩下的点呢？" 说明"例子只能支持猜想"；要断定整段，需对任意两点论证（本阶段可先写出待证目标）。
为什么第 1 行成立而"并集"不成立：取 −1 < 1，则 f(−1)=−1 < 1=f(1)——在两段分别递减的函数，跨过断点可以"升回去"。所以"分别在两区间递减"与"在并集上递减"是两句话。

批改时的三问（可贴在办公桌上）

① 在哪个区间？→ ② 点是任取的吗？→ ③ 每个例子能代表全部吗？

3为何这样讲

  • 批改从"给结论"转向"给追问"：学生照着追问自己修正，比抄一个正确答案更接近理解；追问把批改变成一次微型教学。
  • 三类错误对应定义三要素：定位类型后，追问与修正是有结构的，不依赖灵感。
  • 修正动作必须学生可执行："写出你比较的两点"是动作；"以后仔细点"不是。

4何时不适用

  • 不把诊断卡直接当题库发给学生：先由教师改编成该生能读懂的话；追问的语言要贴合班级。
  • 不用"扣分"驱动诊断：诊断卡的目标是修正理解，不是排名与惩戒。
  • 跨单元迁移要重审：奇偶性、指数函数的"任意"与"区间"各有自己的要素，追问需重新设计（见练习 3）。

练习 1 · 定位错误类型 · 判断题
未回答

学生作业写道："f(x)=x2 在 [0,2] 和 [2,4] 上都递增，所以它在 [0,4] 上递增。"这句推理的问题在哪里？

参考分析 唯一参考，不是唯一标准

参考答案：B。结论在本题碰巧正确，但"分别在 [0,2]、[2,4] 递增 ⟹ 在 [0,4] 递增"这一推理不成立。反例：g(x)=1/x 在 (−∞,0) 与 (0,+∞) 上分别递减，却不能说在并集上递减——取 −1 < 1，g(−1)=−1 < 1=g(1)。正确写法是任取 0 ≤ x1 < x2 ≤ 4 直接论证。

可选追问："换成 1/x，你的推理还成立吗？"——用一个反例让推理自身失效，比直接判错更有教学价值。

参考分析 开放题，以下是参考要点

  • 追问应指向定义要素（在哪里比 / 怎么取点 / 为什么成立），而不是直接给出答案。
  • 修正话术应是学生可执行的动作："写出你比较的两点，再检查符号"——而非"以后仔细点"。
  • 自查重点：三类错误（遗漏区间 / 量词不完整 / 特例代证明）定位是否准确，不混淆"范围"与"量词"。

参考分析 参考要点

可复用的结构：先定位错误类型 → 用追问指向定义要素 → 给出可执行修正。必须替换的内容：奇偶性的"任意 x"是定义域上的全称量词（对 x 与 −x 同时成立），追问要转向 f(−x) 的计算与定义域本身（如 f(x)=1/x 是奇函数，但定义域不含 0 的说法需要核对区间对称性）。
