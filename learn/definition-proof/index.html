定义与证明：把"任意"落到操作上

v0.1.0 草稿 · 未复核 教材未映射 先修 U1 更佳 更新 2026-10-02

1教学困难与先备条件

教学困难：学生会代入具体值判断函数升降，却说不清定义中"任意两个自变量"的含义；常见表现是把两个数值例子当成证明，或者背下"y 随 x 增大而增大"却不会使用。

先备条件（学生侧）：函数符号 f(x) 与区间记号；作差与因式分解；不等式的基本性质。（学生）尚未学习导数——本单元全部论证不用导数。

先备条件（教师侧）：完成过 U1 或熟悉"区间上的比较关系"的引入方式。

本单元的可观察目标：学生能解释"为什么 f(1)=1、f(2)=4 这类两个例子不能完成证明"，并在 [0,2] 上对 f(x)=x2 完成"任取两点"的比较论证。

2示范讲法

第一步 · 用一道判断题暴露直觉

直接给出下面这句话，让学生先表态，再说明理由：

因为 f(1)=1、f(2)=4，所以 f(x)=x2 在 [0,2] 上严格递增。

学生几乎都会同意"结论正确"。这时追问："同意结论的同学，这段理由说服你了吗？为什么？"——把矛盾停在"结论对"与"理由薄"之间，定义的必要性才出现。

第二步 · 五步问题链（约 10 分钟）

步骤教师提问希望学生说出的内容
观察x2 在 [-2,2] 上都是越往右越高吗？不是；要区分不同区间。
明确条件讨论 [0,2] 上的严格递增，需要比较哪两个点？任取 0 ≤ x1 < x2 ≤ 2。
比较函数值f(x2)−f(x1) 可以怎样改写？x22−x12=(x2−x1)(x2+x1)。
说明理由为什么这个乘积大于 0？x2−x1>0，且 x2+x1>0。
回到定义这与只代入 1 和 2 有什么不同？论证覆盖区间内任意满足条件的两点。

第三步 · 板书收敛为一句论证

任取 0 ≤ x1 < x2 ≤ 2，则 f(x2)−f(x1) = (x2−x1)(x2+x1) > 0，故 f(x2) > f(x1)。

两个因子分别在区间条件下定号：x2−x1>0 来自"任取"的排序，x2+x1>0 来自区间 [0,2] 本身。条件的每一项都要有出处——这正是"任意"的操作化。

3为何这样讲

  • "任意"从矛盾中生长，而不是从背诵中生长。先用两个例子制造"结论对但理由薄"的缺口，学生对量词的需求才真实。
  • 因式分解让符号判断变成两个因子的分别定号，每一步都有区间条件支撑，为后续 [−2,0] 等变式留下接口。
  • 问题链的每一步都预期学生回应，教师可以按回应决定追问，而不是按教案顺序推进。

4何时不适用

  • 区间换成 [−2,0]：x2+x1>0 不再成立（此时 x2 递减），不能照搬第 4 步理由。
  • 学生尚未学函数符号：先用具体函数与数值比较，不要先上抽象定义。
  • 不引入导数："导数非负 ⟹ 递增"是后续工具，本单元目标是定义与代数论证。
  • 跨区间（并集）结论要谨慎：见下方选读拓展。
选读拓展 · 用于内容边界核查：g(x)=1/x 在 (−∞,0) 和 (0,+∞) 上分别严格递减，但不能据此说它在这两个区间的并集上严格递减——取 −1 < 1，函数值为 g(−1)=−1 < 1=g(1)，即被反驳。分段递减 ⇏ 并集递减。
