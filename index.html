两次选择，进入一个具体困难

下面是真实工作台的样子：左侧选困难，右侧是给老师的示范与练习。点击左侧单元试试。

函数单调性 · 三个训练单元
内容 v0.1.0 · 草稿 · 未复核
概念引入 示范 · 练习 · 参考分析 · 自查量规
我让学生看图说"哪个函数在增长"，他们都能说对；可一问"你是怎么知道的"，就只会指着图说"它一直在升"。
引入活动 · 从比较两点开始（节选）
U1 概念引入 · 练习前的示范
  • 给出一段图像，先问："比较哪两个点，能支持'这段在上升'？"
  • 再追问："只比较左右端点，够说明整段吗？"
  • 最后过渡到记号：在区间上，任取 x1 < x2，比较 f(x1) 与 f(x2)。
看图直觉 → 比较两点 → 区间记号
完整单元含：先备条件 · 可观察目标 · 何时不适用 · 2 道练习 + 参考分析 + 自查量规。
讲单调性定义时，我举了 f(1)=1、f(2)=4，学生点头说懂了。这算讲清楚了吗？
判断练习 · U2 定义与证明
题干 · 先写下你的判断，再看参考分析

"因为 f(1)=1、f(2)=4，所以 f(x)=x2 在 [0,2] 上严格递增。"
结论是否正确？这段理由是否充分？

示范问题链：观察 → 明确条件 → 比较函数值 → 说明理由 → 回到定义
参考分析区分"支持猜想的例子"与"覆盖任意两点的论证"；改写练习把"你听懂了吗"换成能检查"任意"含义的问题。
作业里总有两类错：写"x 越大 y 越大"漏掉范围；或者拿 f(1)<f(3) 当证明。批改只能打叉，有没有更好的回应方式？
错误—追问—修正卡（节选）
U3 错误诊断 · 三类典型错误
  • 量词不完整："x 越大 y 越大" → 追问："任取两点，在同一个区间里怎么比较？"
  • 特例代证明：f(1)<f(3) → 追问："1 和 3 能代表所有点吗？再取 2 试试？"
识别错误 → 写一条追问 → 给出学生可执行的修正
完整单元含：遗漏区间的诊断（含 1/x 并集反例）· 改写练习 · 新情境迁移。

F01

选择教学困难

仅开放"函数单调性"专题：概念引入、定义与证明、错误诊断三个入口，两次选择内进入单元。

F02

短训与分步示范

每单元：教学困难 → 先备条件 → 可观察目标 → 示范讲法 → 为何这样讲 → 何时不适用。

F03

教学判断练习

判断 / 改写 / 迁移三型练习，配审核过的参考分析与任务级自查量规；四种作答状态可区分。

F04

教学片段编辑

目标、问题链、预期错误、理解检查四项核心字段；本地自动保存、复制为新版本、恢复备份。

F05

预览与导出

打印 / 另存 PDF、复制文本、Markdown 与可恢复 JSON 备份；导出稿标注"个人改编稿"。

F06

使用记录与复盘

区分"计划使用 / 已实际使用 / 未使用"，复盘三项：观察到什么、我的解释、下次改什么。
